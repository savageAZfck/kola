# Security

Report vulnerabilities privately to savagetism@icloud.com — do not open
public issues for exploitable weaknesses.

Scope: attestation signature verification, journal hash-chaining, head-pinning logic, audit replay correctness.

Out of scope: the transport carrying journals between organisms, the integrity of the ledger being witnessed (that is the witnessed chain's problem — kola pins it, it does not validate semantics) (see THREAT_MODEL.md).
